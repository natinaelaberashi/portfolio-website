# Operations KPI Report

## Core KPIs

- Total cases
- SLA compliance
- Average response time
- Average resolution time
- Open/pending volume
- High/Critical case volume

## Breakdown

Review KPIs by category, priority, channel, team, and root cause.

## Management Questions

1. Which categories generate the most cases?
2. Where are SLA misses concentrated?
3. Which root causes repeat?
4. Which cases have the greatest business impact?
5. What process or monitoring improvement should be prioritized?

This template can be implemented in Excel or Power BI.
