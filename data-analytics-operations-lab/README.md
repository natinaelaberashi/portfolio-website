# Data Analytics for Operations Lab

A portfolio project showing how an operations analyst can turn support and transaction data into KPI reporting and actionable insights.

## What it demonstrates

- SQL-based KPI analysis
- Volume and trend analysis
- SLA compliance
- Category and channel comparison
- Exception-rate analysis
- Root-cause-oriented reporting
- Management-ready operational insights

## Project structure

- `data/operations.csv` — synthetic operational dataset
- `sql/kpi_analysis.sql` — reusable SQL analysis
- `reporting/kpi-report.md` — KPI reporting template
- `insights.md` — analytical findings

The project is intentionally tool-agnostic so the same dataset can be used with Excel, Power BI, SQL, or Python later.
