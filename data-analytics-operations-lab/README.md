# Data Analytics for Operations Lab

A portfolio project showing how an operations analyst can turn **support and transaction data into KPI reporting and actionable operational insights**.

## Scenario

An operations team needs a concise view of volume, SLA performance, exceptions, categories, channels, and recurring causes.

## Analysis Flow

```text
Operational Data
      ↓
KPI Calculation
      ↓
Volume / Trend Analysis
      ↓
SLA & Exception Review
      ↓
Root-Cause Analysis
      ↓
Management Reporting
```

## What It Demonstrates

- SQL-based KPI analysis
- Volume and trend analysis
- SLA compliance
- Category and channel comparison
- Exception-rate analysis
- Root-cause-oriented reporting
- Management-ready operational insights

## Project Structure

- `data/operations.csv` — synthetic operational dataset
- `sql/kpi_analysis.sql` — reusable SQL analysis
- `reporting/kpi-report.md` — KPI reporting template
- `insights.md` — analytical findings

## Skills Demonstrated

SQL • KPI Analysis • SLA Monitoring • Trend Analysis • Root-Cause Analysis • Operational Reporting • Business Communication

## Tool-Agnostic Design

The dataset can be extended or analyzed with **Excel, Power BI, SQL, or Python** without changing the underlying operational questions.

## Data Integrity

All data is synthetic and created for portfolio demonstration.
