# Dashboard Insights

These observations are calculated from the synthetic sample and are **not real employer results**.

## Initial findings

- Transaction cases show the highest concentration of exceptions in the sample.
- Integration issues and system errors are recurring exception categories.
- Higher-priority transaction cases require closer SLA monitoring.
- Access and account cases generally resolve faster than transaction cases in this sample.
- Team-level workload should be reviewed together with SLA compliance rather than volume alone.

## Management actions demonstrated by the project

1. Review recurring transaction and integration exceptions.
2. Create targeted investigation/runbook guidance for repeat root causes.
3. Monitor P1/P2 transaction cases separately.
4. Use weekly KPI reviews to identify emerging SLA pressure.
5. Drill from management KPIs into case-level evidence before deciding on process changes.
